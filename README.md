# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 功能开关、发布计划版本、灰度批次、审计记录四类业务对象。
- 规则组合、模拟用户命中、逐步调整流量和定时生效。
- 产品/研发双审批、开始灰度、紧急停止、回滚和恢复草稿。
- 离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化。

## 并发与可靠性机制
- **版本化发布计划**：每次修改规则/放量/定时都生成新的计划版本，审批绑定具体版本；版本未通过双审批时发布会以"审批失效"拒绝。
- **跨标签页乐观并发**：持久化状态携带 `revision`，任何页面提交前校验；另一页面已写入时当前页标记"页面已过期"并拒绝提交，同步后才能继续，杜绝按旧批准开始灰度。
- **生效快照**：开始灰度时冻结批次快照，命中模拟和审计记录读取快照；灰度中改规则只生成待审版本，不影响当前批次。
- **幂等停止/回滚**：紧急停止与回滚只处理当前批次，批次记录已执行操作、审计携带幂等键，重复操作不重复记录。
- **失败重试队列**：写入失败保留重试项和原状态快照（`revision` + `writeSeq` 排序，重试时不覆盖他人新数据），队列独立持久化，重启后仍能分清当前批次、待审版本和失败项。
