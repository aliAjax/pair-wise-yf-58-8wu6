# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 功能开关、发布计划、审计记录三类业务对象。
- 规则组合、模拟用户命中、逐步调整流量和定时生效。
- 产品/研发双审批、开始灰度、紧急停止、回滚和恢复草稿。
- 离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化。

## 并发与一致性（版本化 + 生效快照 + 重试队列）
- **版本化与审批绑定**：每次修改规则 / 放量 / 定时都生成新的发布计划版本，审批记录绑定具体版本；旧页面提交时若检测到审批版本落后于草稿版本，提示「审批已失效」并拒绝发布（乐观并发守卫）。
- **生效快照**：灰度开始时把当前规则、放量、定时固化为不可变批次快照。灰度期间命中模拟读取生效快照，改规则只生成待审版本，不影响运行中的批次。
- **幂等停止/回滚**：紧急停止或回滚只处理当前批次，重复操作不重复写入审计记录。
- **写入失败重试**：开启「模拟写入失败」后执行业务写入，失败时保留原状态、操作进入重试队列（发件箱模式）；可重试或丢弃。
- **重开可辨**：重新水合后可分清当前批次（生效快照）、待审版本（草稿）和失败项（重试队列）。
- **跨标签页同步**：监听 `storage` 事件，另一标签页写入后本页自动重新水合。

## 演示要点
1. 审批 v3 → 点「模拟另一标签页改规则」→ 再点「开始灰度」→ 触发「审批已失效」。
2. 重新审批 v4 并开始灰度 → 命中模拟读取生效快照；此时改规则只生成待审版本。
3. 灰度中连续点「紧急停止」/「回滚」→ 审计记录不重复。
4. 开启「模拟写入失败」→ 执行紧急停止 → 原状态保留、失败项入队 → 点「重试」补执行。
